How on-chain voting works

Miners state their preference in every block they mine: the ForkState field at the start of the header — the flag this page parses — carries one optional vote for the next fork.

  • Vote. For 119 hours (14,280 blocks) each new block can add one vote to its chain's running total.
  • Count. In the final hour (120 blocks) the chains average their totals with their neighbors, converging on a single network-wide result.
  • Decide. If at least two-thirds of the voting blocks signaled support, the new rules apply from the first block of the next epoch; otherwise the current rules stay and voting starts over.

Upgrades therefore activate only when a supermajority of hashrate backs them, not on a deadline set by developers. For the full story, read Kadena — on-chain voting for miners by KDA Community Edition.
